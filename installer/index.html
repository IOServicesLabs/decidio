decidio by IO Services

Install decidio on your board and set it up

decidio puts a small decision model on an ESP32-S3 camera board. The model answers questions about what the camera sees and what the microphone hears. Rules on the board use the answers to set a pin or to send an alert.

Use this page to install an idea on the board over USB. Then connect the board to Wi-Fi and set up its alerts. You do not install software on your computer.

  • Seeed XIAO ESP32S3 Sense: camera and microphone.
  • ESP32-S3-CAM with the ESP32-S3-EYE pin layout: camera, no microphone.
  • Other ESP32-S3 boards with 8 MB flash or more: no camera, no microphone. The rules use the Wi-Fi movement score, the pins, sensors and the other boards.

1. Board

Select your type of board.

Type of board

Loading the boards...

The firmware is the same for each board. When the board starts, the firmware finds the camera and the microphone. Your selection changes only the model. If you do not know your type of camera board, select the first type. It operates on each camera board. On a board without a microphone, its sound questions are off.

For a board that has no camera, or a board that must not use its camera, select a type without a camera. The firmware then does not look for a camera. The microphone type gives the sound ideas. The type without camera and microphone gives the ideas that use the Wi-Fi movement score. On the page of the board, you can add rules on pins, sensors and other boards. Only ESP32-S3 boards operate with this firmware.

2. Idea

Select one idea. An idea is the base model with a set of rules. You can change the rules later on the page of the board.

3. Install

No idea is selected. Select an idea in step 2.
This browser cannot connect to USB devices. Use Chrome or Edge on a computer. Open this page over https:// or from localhost.
  1. Connect the board to this computer with a USB cable. Use a cable that carries data. A cable for charge only shows no port.
  2. Seeed XIAO ESP32S3 Sense: push and hold the small B (BOOT) button while you connect the USB cable. Then select the port "USB JTAG/serial debug unit".
  3. ESP32-S3-CAM: connect the cable to the USB socket with the label UART.
  4. Click Connect and install.
  5. Select the port of the board in the window of the browser.
  6. Follow the instructions in the window until the install is complete.
  7. The board starts again. Go to step 4 to set it up. If the board does not start, disconnect the USB cable and connect it again.

CAUTION: The install replaces the firmware and the model on the board. The Wi-Fi settings, the page password and the alert settings stay on the board.

The new idea starts with its own rules. Rules that you changed on the page of the board for a different idea do not stay.

WARNING: A model makes errors, and a rule operates on an error as it does on a correct answer. GUIDE.md gives the error rates. Test each idea in your room. Do not use decidio as a safety device or as an alarm.

4. Set up

Use this step with each board that has decidio firmware. A board that you installed with the decidio install command also operates here, so you can start at this step.

  1. Connect the board to this computer with the USB cable.
  2. Click Connect to the board.
  3. Select the port of the board in the window of the browser.

The settings go to the board over USB only. This website does not send them to a server.

Only one program at a time can use the port. Close the install window and other serial programs first.

Settings of the board

Board summary

Connect to the board to show its summary.

Wi-Fi

Type the name and the password of your Wi-Fi network. The board uses 2.4 GHz networks only.

Leave the password empty for an open network. Otherwise the password has 8 to 63 characters.

Address of the board:

Open the page of the board

Some phones cannot open the address with .local. Use the address with numbers on them.

Without a USB connection: join the open Wi-Fi network decidio-xxxx of the board with a phone. The setup page of the board opens. If it does not open, go to http://192.168.4.1.

Page password

Without a page password, each person on your network can open the page of the board and change it. The user name for the page is decidio.

Use 60 characters or fewer. Do not use the characters " and \.

Alerts

When a rule fires, the board can send an alert to Telegram, to a webhook or to an MQTT broker. Type the settings of one or more destinations. Then click Save alerts.

The board does not show the values that it has. An empty field keeps the value that is on the board.

Telegram

In Telegram, send /newbot to @BotFather to make a bot. Send a message to your new bot. To find your chat ID, open https://api.telegram.org/bot<token>/getUpdates in a new tab. The chat ID is the number after "chat":{"id":.

Webhook

For example ntfy, Discord, Slack or Home Assistant.

Header form: Name: value. For example: Authorization: Bearer abc123.

MQTT

Topics: decidio/decidio-xxxx/event/<rule> and decidio/decidio-xxxx/status.

CAUTION: The board keeps the Wi-Fi password, the page password and the tokens in its flash memory without encryption. A person who takes the board can read them. Use a bot that you made only for this board.

Restart

The board reads a new page password when it starts.

Console log

The lines that the board sends, and the commands that this page sends. Copy them when you ask for help. The page replaces each password, token and address that it sent with [hidden].
